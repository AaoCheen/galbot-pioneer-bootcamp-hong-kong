# 控制与操作：从关节空间到抓取时序

## 关节限位与 URDF

URDF 用 link 描述刚体、joint 描述连接关系及转轴，限位约束允许的关节范围。可视化模型有助于理解关节正方向和参考零位，但模型里的可达姿态不自动保证实机路径无碰撞。

运动前要区分三种约束：关节位置限位、速度等运动约束，以及机身/环境碰撞约束。运动学求解成功只覆盖其中一部分。

## 两种都是“7 个数”的表示

| 表示 | 格式 | 回答的问题 |
|---|---|---|
| 右臂关节角 | q1…q7，单位 rad | 每个关节转了多少 |
| 末端位姿 | x,y,z,qx,qy,qz,qw | 末端相对指定坐标系在哪里、如何朝向 |

两者都不包含夹爪宽度。FK 从关节角和模型求末端位姿；IK 从目标位姿及约束求可能的关节解，冗余机械臂可能存在多个解。

本次已有[关节状态记录](../labs/joint-state.md)与[末端位姿记录](../labs/end-effector-pose.md)。末端查询相对 `base_link`，工具帧为安装坐标系；没有把它自动当作夹爪指尖，也没有将相对坐标高度当作距地高度。

## 控制接口要理解的四件事

- 关节目标是绝对角度还是增量，名称顺序与数值顺序是否一致。
- 速度参数的单位是 rad/s，超时参数的单位是秒。
- 阻塞返回用于程序时序；超时不等于急停，非阻塞也不自动带来实时控制。
- 接口返回成功不证明夹爪抓住了目标物体，应结合实际反馈与任务观察。

## 五个示教关键点

课程示教方案记录 start、pregrasp、grasp、preplace、place 五组关节姿态及夹爪参数。这是关键点回放，不是完整连续遥操作轨迹。

```text
打开夹爪 → 起始位 → 预抓取位 → 抓取位 → 闭合
         → 返回预抓取位 → 预放置位 → 放置位 → 打开
         → 返回预放置位 → 起始位
```

如果预抓取和抓取几乎相同，“回到预抓取位”可能没有明显提起效果。关节空间插值也不保证末端走直线。这些问题需要在坐标系、运动学和场景中分析，不能只看脚本步骤名称。

## 下一步验证

记录接近距离、夹爪反馈、提起过程、物体是否稳定以及放置结果。当前公开材料支持接口理解与关键点流程分析，尚未提供固定抓取的重复试验成功率。

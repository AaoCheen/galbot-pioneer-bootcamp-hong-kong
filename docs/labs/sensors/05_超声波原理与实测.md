# 超声波：八方向距离与实测

[返回传感器笔记索引](./README.md)

记录日期：2026-11-12。实机数据来自用户在 `robot-hpu` 的终端输出；助手未重新连接机器人。

## 读取方式与观察方法

脚本：`04_ultrasonic_observe.py`。

`SensorType.BASE_ULTRASONIC` 用于启用整组；`UltrasonicType.FRONT_LEFT` 等用于选择单个方向读取。

方向名称依本地官方示例：FRONT_LEFT、FRONT_RIGHT、RIGHT_LEFT、RIGHT_RIGHT、BACK_LEFT、BACK_RIGHT、LEFT_LEFT、LEFT_RIGHT。脚本逐一打印名称，名称对应的精确安装位置和波束方向仍需看实机标注，不能凭遍历次序画安装图。

**操作**：机器人静止，在安全间距外朝某一探头摆放纸板，比较前后读数；再改变纸板朝向。不要用身体贴近底盘、让机器人临近台阶或做防跌落测试。

**理解**：软材料可能吸声；斜面可能把回波反射到别处；波束内多个物体也会影响读数。返回的是距离信息，不是物体类别。课程写 distance 单位为米，但量程、最小盲区与无回波编码应核对实际设备。

脚本将缺失、非有限、非正距离记为待排查，不把它们解释为“前方无障碍”。正数也可能是驱动约定的超量程哨兵值，需核对设备协议。没有套用讲义的示例量程作为通用阈值。

“超声波可防跌落”需要朝向、安装和算法支持。本次没有证据确认 G1 对应探头具备该能力，不应以此测试台阶安全性。

**自测**：纸板放近后读数不变，可能有哪些原因？对应探头判断错、波束未覆盖、盲区、缓存、无回波编码或驱动异常；不是立即判定探头损坏。

## 本次实测与 2 cm 待确认项

来源为用户粘贴的终端输出片段，助手未连接实机。报告路径为 `~/galbot-learning/sensors/output/20261112_164959_487577_ultrasonic`。

| 方向枚举 | 最后可见一轮距离（m） |
|---|---:|
| FRONT_LEFT | 0.020 |
| FRONT_RIGHT | 0.020 |
| RIGHT_LEFT | 2.417 |
| RIGHT_RIGHT | 2.427 |
| BACK_LEFT | 1.129 |
| BACK_RIGHT | 0.933 |
| LEFT_LEFT | 0.020 |
| LEFT_RIGHT | 2.428 |

最后可见一轮的八个方向拥有相同 timestamp_ns，符合整组数据共用时间戳的可能情况，但不证明八个探头同时发射或各自独立更新。片段中 LEFT_RIGHT 的前一轮和后一轮距离均为 2.428 m，时间戳前进约 0.440 s；距离不变不等于数据没有更新。完整脚本报告八项 OBSERVED，表示其检查窗口内读数可解析且时间戳曾推进；用户没有粘贴完整所有轮次，不能逐项独立复核全部时间序列。

`positive_distance=true` 仅检查 distance 是有限正数，不检查量程、回波有效位或标定。三个方向均报告恰好 0.020 m，不能直接判定有三个物体距探头 2 cm，也不能判定其正常或故障。待核对实际近物、自体遮挡、最小值钳位或无效/盲区编码；以上只是候选解释。

下一步保持机器人静止，先目视检查对应探头附近，再在安全间距外移动纸板，观察对应方向是否随距离改变。若周围开阔而仍固定 0.020，应查服务与设备协议定义，不能将其作为可靠近障距离。方向名称对应的精确安装位置仍待实机核实。

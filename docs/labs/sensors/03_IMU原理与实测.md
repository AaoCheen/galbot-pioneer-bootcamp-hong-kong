# IMU：原理、操作与实测

[返回传感器笔记索引](./README.md)

记录日期：2026-11-12。实机数据来自用户在 `robot-hpu` 的终端输出；助手未重新连接机器人。

## 观察方法与原理

脚本：`02_imu_observe.py`。让机器人保持当前安全静止状态，采集 10～30 轮；不用推动、倾斜或转动机器人。

### 术语与机制

- `accel`：加速度计读数，课程单位 m/s²。常见输出包含重力相关分量；静止不代表三个分量全零。
- `gyro`：角速度，课程单位 rad/s；静止时通常接近零，但会有噪声和零偏。
- `magnet`：示例提供的磁场字段；单位和有效性需核对当前服务，字段存在不证明传感器有效。
- `accel_norm = sqrt(ax² + ay² + az²)`：加速度模长。如果输出包含重力且单位正确，静止时常接近 9.81。它比“Z 轴必须为正 9.8”更少依赖安装方向。
- 零偏是偏移；漂移是误差经过积分随时间积累。计算静止基线只是观察，不是完整标定。

例：静止时读到 `[9.8, 0, 0]`，可能是重力主要投影到 X 轴。不要仅因 Z 轴不是 9.8 就判坏。若模长接近 0，则要区分数据无效、服务去重力、单位不符等情况，不能直接定为正常。

脚本打印每轮三轴值和模长，结束后对**唯一时间戳**计算模长均值、标准差及范围。重复缓存不会被重复计入此统计。只有一个有效时间戳时不计算标准差；模长统计也不能替代各轴零偏标定。

**观察任务**：

1. 比较 accel 三轴分量，重力主要体现在哪个方向？
2. 看 gyro 模长是否接近零；不要用四舍五入后的 `0.000` 证明完全无噪声。
3. 看 timestamp_ns 是否推进；相同数值不等于缓存不更新。
4. 如要比较日后经现场人员按流程执行的运动片段，另开一次记录，写明场景。本组脚本不发起运动。

**自测**：匀速直线运动时，加速度能否一直明显非零？不能，速度非零不等于加速度非零。这里也没有直接返回姿态角，不能把 accel 三轴当作 roll/pitch/yaw。

## 本次单次读取与连续实测

### 单次读取

用户先运行 `python 01_sensor_inventory.py`，启用 `TORSO_IMU`。初始化耗时 5.191 s，单次 getter 耗时约 0.0853 ms，返回 accel、gyro、magnet 和 timestamp_ns。加速度模长为 10.171063 m/s²，角速度模长为 0.004995 rad/s。

结果 WARN 的原因是只有一个时间戳，无法比较是否推进；不是已经确认 IMU 故障。SDK 枚举清单包含多个 IMU、雷达和相机类型，只能证明软件提供这些名字，不能作为实机硬件安装清单。

### 连续观测

来源：用户提供的 `robot-hpu:~/galbot-learning/sensors` 终端输出，命令为 `python 02_imu_observe.py --samples 30 --interval 0.2`。助手解析了粘贴结果，未重新连接或执行实机脚本。机器人是否全程静止尚未由用户明确确认，以下静止基线解释以全程静止为前提。

| 指标 | 本次观测 |
|---|---|
| 初始化耗时 | 5.416 s |
| IMU 来源 | TORSO_IMU |
| 有效时间戳 | 30 个，互不相同，严格递增 |
| 首末设备时间戳间隔 | 约 5.816 s |
| 首末主机读取时刻间隔 | 约 5.815 s |
| 加速度模长均值 | 10.169179 m/s² |
| 加速度模长样本标准差 | 0.064867 m/s² |
| 加速度模长范围 | 9.979943～10.265279 m/s² |
| 角速度模长均值 | 0.003018 rad/s，约 0.173°/s |
| 角速度模长样本标准差 | 0.001182 rad/s |
| 角速度模长范围 | 0.001119～0.005733 rad/s |

这段窗口内观察到数据更新，没有反复读到同一时间戳的证据。约每 0.2 秒一次是本脚本的观察节奏，不能推断驱动只发布 5 Hz；时间戳推进也不能证明绝对新鲜度。

若机器人全程静止，读数表现为小幅波动，但加速度模长均值比 9.81 高约 3.66%。安装倾斜能改变三轴重力分量，不能单独解释向量模长偏大。偏差可能涉及标度、零偏、振动或服务定义，短时间片段不足以归因，也不能直接据此实施减去常量的标定。

从粘贴的 30 条记录计算，三轴加速度有符号均值约为 `[0.145654, 0.341369, 10.162259] m/s²`，角速度有符号均值约为 `[0.000123, -0.000426, -0.000033] rad/s`。这些是该片段的算术统计，不能脱离静止条件直接当作标定参数。

角速度模长为非负量，噪声正负波动不会在模长均值中抵消，因此不能把 0.003018 rad/s 直接当成陀螺仪零偏或真实转速。估计静止零偏应研究每个轴的有符号均值，并确认静止条件、足够采样时长和温度稳定性。

本次结论为“数据可解析且时间戳推进”，不扩展为传感器精度或硬件健康验收。后续若需核查偏差，可保持相同静止条件延长到 300 轮、间隔 0.2 秒，再比较均值与波动。雷达和超声波结果见本文件夹对应专题。

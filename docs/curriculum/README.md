## 课程学习方式

每一阶段按“直觉 → 术语 → 接口/机制 → 现有证据 → 下一步验证”整理。现场视频反映活动中的机器人演示，不据此推断代码作者、控制方法或独立完成程度。

## 前置知识

Linux 用于目录、环境和进程排查；Python 用于 SDK 调用与数据整理；Vim 用于远端文件编辑。学习重点是理解代码运行在何处、依赖什么服务，以及返回值能证明什么。

## 结营与复盘

值得积累的提交物包括：运行环境、代码版本、关键配置、分阶段日志、演示视频、失败原因及后续改进。课程考核标准以官方当前版本为准；本项目不将课程覆盖情况等同于认证通过。

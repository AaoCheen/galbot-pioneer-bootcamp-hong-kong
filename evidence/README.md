## 已有实机输出

记录整理日期为 2026-11-12。状态与传感器记录来自学习者提供的机器人终端输出，并非整理过程中再次远程运行所得。

| 证据 | 内容 | 位置 |
|---|---|---|
| 关节反馈 | 关节组/关节名查询、位置与完整状态解释 | [关节笔记](../docs/labs/joint-state.md) |
| 末端位姿 | 右臂 7 关节角与相对 base_link 的位姿 | [末端笔记](../docs/labs/end-effector-pose.md) |
| 连续 IMU | 30 条记录、相对时间、加速度/角速度/磁场字段 | [JSONL](imu_30_samples.jsonl) |
| 雷达观察 | 10 次读取、9 个不同时间戳、每帧 19968 条点记录 | [雷达笔记](../docs/labs/sensors/04_雷达原理与实测.md) |
| 超声波 | 八方向末轮值与程序汇总，非完整逐轮记录 | [超声波笔记](../docs/labs/sensors/05_超声波原理与实测.md) |
| 综合检查 | IMU、雷达与八方向超声波的末轮与汇总 | [综合笔记](../docs/labs/sensors/06_综合检查与时间戳.md) |

IMU JSONL 保留观测数值，把设备时间戳改成相对首帧的秒数，移除了主机单调时间等现场标识。原始磁场单位与有效性尚未核实。统计值是观测特征，不是设备精度规格。

## 离线测试

`scripts/sensors/test_offline.py` 包含 6 个测试用例，验证大小端、字段偏移、点与行填充、截断、NaN、缺失字段、时间戳判定及模拟 SDK 脚本流程。所有测试均不连接机器人。

## 现场演示与课程研读

首页 GIF 来自学习者提供的现场视频，只展示画面内机器人动作。视频不能单独证明动作策略由本人独立开发，也不能作为任务成功率或认证通过的依据。

视觉交互、SLAM、导航与移动抓取部分为课程研读和后续实验设计；提供的移动抓取任务样本有空的关键点和未完成字段，未据此认定完整任务成功。
